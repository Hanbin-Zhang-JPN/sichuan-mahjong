# 蜀间 · 四川麻将

**[点击这里，直接开始游玩](https://hanbin-zhang-jpn.github.io/sichuan-mahjong/)**

一人对战三位 AI 的四川麻将「血战到底」。无需注册、下载或安装；在 MacBook Air M3、其他电脑及手机的现代浏览器中打开上面的地址即可。所有逻辑在你的浏览器本地运行，不上传牌局，不涉及现金或奖励。

## 操作

1. 选三张同一花色的牌，点击「确认换牌」。也可使用「建议换牌」。
2. 选择缺万、缺条或缺筒。
3. 单击选中手牌，再点击「打出」或按 Enter；双击也可直接出牌。
4. 可以碰、杠、胡时，牌桌会出现相应按钮。「建议」只选中推荐牌，不会自动打出。
5. 你胡牌后，其他玩家继续；本局结束展示分数、胡牌顺序、手牌和每一笔积分。

## 本版桌规

四川麻将各地规则不同，本项目明确采用以下休闲桌规，不宣称适用于所有地区。

- 万、条、筒各九种，每种四张，共 **108 张**；没有字牌和花牌。
- 四人各自争胜，无队友；首局你坐庄，此后庄家按座位轮换。
- 庄家 14 张，其余 13 张。开局同花色换三张，随机交给下家、上家或对家，再定缺。
- 缺门未清空必须先打缺门，不能碰杠或胡。只能碰、杠、胡，**不能吃**。
- 胡牌结构为四组顺子/刻子加一对，或七对；必须清空缺门。
- 血战到底：胡牌者退出本局，其他人继续，三家胡牌或摸完牌墙才结束；可一炮多响。
- 胡优先于碰杠；无胡时，最近的碰/杠响应者优先。杠从牌墙尾部补牌；补杠可以被抢胡，暗杠、点杠不可以被抢胡。
- 放弃点炮胡后，直到再次自行摸牌不能胡同分或更低分的点炮牌。剩余四张及以下能胡必须胡；自摸也必须胡。
- AI 每次单独随机等待 **500～1500 毫秒**。使用向听数、可见进张、牌河危险度决策；不读取牌墙顺序或其他人的暗牌。

### 积分

底分 1。基础分为 `2^番数`，最多四番，最高基础分 16。

| 番型 | 加番 |
| --- | --- |
| 平胡 | 0 |
| 对对胡 | 1 |
| 七对 | 2 |
| 清一色 | 2 |
| 金钩钓（四组副露） | 1 |
| 每根（整副胡牌中四张同牌） | 1 |
| 杠上花、杠后炮、抢杠胡、海底胡 | 各 1 |

符合条件可叠加；七对不再叠加对对胡。龙七对按七对加根计。金钩钓可与对对胡叠加。海底胡指最后一张摸牌自摸或最后一张摸牌打出后点炮胡。

- 点炮：点炮者付基础分；一炮多响分别支付。
- 自摸：其他未胡者各付基础分 +1。
- 点杠：点杠者付 2。补杠：其他未胡者各付 1。暗杠：各付 2。
- 已胡者不参与此后发生的自摸和杠分。
- 牌墙耗尽查花猪：未胡者还持缺门牌，向每位非花猪（包括已胡者）付 16。
- 查叫：未胡且非花猪者中，未听牌者按各听牌者能胡的最高基础分赔付。听牌检验不扣除外部已经可见的牌。
- 花猪、未听牌者退还本局收到的杠分。查花猪者不重复承担查叫罚分。
- 不启用呼叫转移、天地胡、将对、幺九、门清中张加番。
- 每一笔积分为零和转移；所有玩家本局积分之和为零。

基础玩法参考 [麻將國四川麻将玩法说明](https://mahjongo.com/zh/sichuan)，计分上限等以本项目上述桌规为准。

## 离线运行

下载仓库 ZIP 并解压，直接双击 **index.html**，不需要 Node.js 或其他软件。游戏不依赖外部字体、图片、接口或第三方库。下载后的文件可完全离线运行。

## 开发与测试

采用原生 HTML、CSS、JavaScript。`rules.js` 是可单独运行的规则引擎；`app.js` 管理页面、输入及 AI 定时；没有构建步骤。

如已安装 Node.js，可运行：

```sh
node --test tests/rules.test.js
node --check app.js
```

自动化覆盖发牌、换牌、定缺、胡牌、算番、过水、一炮多响、抢杠、查叫、退杠与多局 AI 模拟；模拟逐步检查 108 张实体牌守恒和零和积分。

GitHub Pages 从 `main` 分支根目录发布。界面和逻辑全部静态，不需要服务器端或密钥。刷新页面会开始新的一桌，不保存游戏进度。
